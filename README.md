# Arpan Pandey — Portfolio Website

Personal portfolio website built with vanilla HTML, CSS, and JavaScript.

🌐 **Live at:** [arpanpandey.com.np](https://arpanpandey.com.np)

---

## About

A fully responsive, dark-themed portfolio showcasing my projects, skills, and experience as a Software Developer specializing in AI & Machine Learning.

---

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- [Formspree](https://formspree.io) — contact form
- [Font Awesome](https://fontawesome.com) — icons
- [Google Fonts](https://fonts.google.com) — Inter & Fira Code
- Hosted on [GitHub Pages](https://pages.github.com)

---

## Features

- Responsive design (mobile, tablet, desktop)
- Animated typing effect in hero section
- Scroll reveal animations
- Project cards with Problem → Built → Result format
- Working contact form via Formspree
- Dark theme with single accent color
- Accessible (`aria` labels, `prefers-reduced-motion` support)

## Local Development

No build tools needed — just open the file directly:

```bash
# Clone the repo
git clone https://github.com/anky32/portfolio.git

# Open in browser
open index.html
```

Or use the **Live Server** extension in VS Code for auto-reload on save.

---

## Deploying Changes

```bash
git add .
git commit -m "your message"
git push
```

GitHub Pages auto-deploys on every push to `main`. Changes are live within ~1 minute.
